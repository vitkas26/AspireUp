# AspireUp

Early Android/Jetpack Compose scaffold for a personal growth app idea. The current implementation contains a splash screen and a placeholder `Hello App` screen; the planned psychology, numerology, and lifestyle features are not implemented yet.

## Status

Prototype, not a released application. The `app`, `core`, and `core-ui` modules are present, but the product flow is still to be built. This repository is kept unarchived for possible future development and is not included in the current project showcase.
